# SGCAE · Sistema de Gestión y Control de Acceso de Empleados

Backend con API REST para administrar empleados y credenciales, registrar las entradas y salidas en los
puntos de acceso de la sede y consultar el historial de accesos.

Seguimiento 2 de **Programación Distribuida**: Clean Architecture, DDD y CQRS sobre ASP.NET Core Web API,
Entity Framework Core y SQL Server.

## Flujo de trabajo

`main` guarda las versiones entregadas, `develop` integra el trabajo del equipo y cada requerimiento funcional
se desarrolla en su propia rama `feature/*`, que se integra a `develop` por pull request.
